## 서버 기동·종료

- **기동**: 미실시. 테스트 전 `GET /v3/api-docs` → 200으로 기존 서버 가용 확인.
- **종료**: **생략** (사용자가 수동 기동 중인 서버이므로 종료하지 않음).
- 비고: `GET /actuator/health`는 500을 반환했으나 API 엔드포인트는 정상 응답.

## 시드·데이터 영향

- 정상 전이 테스트로 `IB-CTR01-001`, `OB-CTR02-001`이 status `00` → `90`으로 변경됨 (동적 선택).
- `IB-INVALID-TRANS`, `OB-DONE`, `IB-CTR01-020`, `IB-CTR01-010`은 상태 미변경(거부 또는 조회만).

## 재현 명령

```powershell
# Health
curl.exe -s -o NUL -w "%{http_code}" http://localhost:8080/v3/api-docs

# F4
curl.exe -s "http://localhost:8080/api/status-transitions/rules?order_kind=INBOUND"
curl.exe -s "http://localhost:8080/api/status-transitions/rules?order_kind=OUTBOUND"

# F1
curl.exe -s "http://localhost:8080/api/inbound/orders?status_code=00"
curl.exe -s "http://localhost:8080/api/inbound/orders/IB-INVALID-TRANS"
curl.exe -s -X POST "http://localhost:8080/api/inbound/orders/{orderNo}/transition" -H "Content-Type: application/json" -d "{\"to_status\":\"10\",\"changed_by\":\"test-be\",\"change_reason\":\"seq-10\"}"

# F2
curl.exe -s "http://localhost:8080/api/outbound/orders"
curl.exe -s "http://localhost:8080/api/outbound/orders/OB-DONE"

# F3
curl.exe -s "http://localhost:8080/api/dashboard/summary?center_no=CTR01"
curl.exe -s "http://localhost:8080/api/dashboard/history/recent?limit=5"
curl.exe -s "http://localhost:8080/api/dashboard/history/trace?order_type=INBOUND&order_no=IB-CTR01-020"
```
